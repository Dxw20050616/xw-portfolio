HOMEPAGE BACKGROUND VIDEO — NOTES
================================

Source supplied by the site owner:
    C:\Users\deng\OneDrive\Desktop\视频素材\11月22日(1).mp4

The source is a 25.2 s, 3840 x 2160, 60 fps colourful forest scene with
foxes and animated plants. It contains no interface text, HUD, captions,
watermark or other overlay UI.

The full clip is used as a silent background loop. Resolution and frame rate
are preserved:
- audio removed;
- transcoded from H.264 (source) to a web-compatible H.264 / yuv420p file;
- 3840 x 2160, 60 fps, High profile, level 5.2, CRF 20;
- looped by the video element;
- no downscaling and no text or UI added to the output.

Files:
    home-loop.mp4          (~43.2 MB, 3840 x 2160 / 60 fps primary)
    home-loop-1440.mp4     (~20.4 MB, 2560 x 1440 / 60 fps fallback)
    home-loop-poster.webp  (~211 KB, 1920 x 1080)

The 4K file is used first. If it cannot load / decode, the page switches to
the 1440p fallback automatically so the background keeps moving. The page
does not require a play-button click and has no playback control UI.

Rebuild with scripts/build_home_video.py.

Source supplied by the site owner:
    C:\Users\deng\OneDrive\Desktop\视频素材\视频3.mp4
